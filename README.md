# Calculadora de Índice de Masa Corporal (IMC)

Este repositorio contiene la lógica de programación y el diseño de flujo para una calculadora de Índice de Masa Corporal (IMC)

## Descripción del Proyecto
El programa solicita al usuario sus medidas (peso y estatura) para realizar el cálculo matemático del IMC basado en los estándares oficiales de la OMS. Además del resultado numérico, el sistema evalúa la cifra para devolver un diagnóstico preciso:
- Peso bajo
- Peso normal
- Sobrepeso
- Obesidad

## Tecnologías Utilizadas
* **Lenguaje:** Java
* **Entorno de Desarrollo:** Visual Studio Code
* **Diseño Lógico:** Diagramas de Flujo y Pseudocódigo

## 📂 Contenido del Repositorio
1. `CalculadoraIMC.java`: Código fuente funcional con la lógica de cálculo y validaciones.
2. `Calcular_IMC.psc`: Estructura lógica en pseudocódigo.
3. `Diagrama de flujo IMC.png`: Representación visual de la toma de decisiones del sistema.
